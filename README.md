# Frost Heave

Frost Heave: a no-guess hidden-hazard logic puzzle. Find the potholes and frost heaves on a snowy Vermont back road and plow it open.

Play: https://play.btownbrief.com/frost-heave/

Part of Btown Games (https://play.btownbrief.com). Plain static site, no build step; pushing to `main` deploys GitHub Pages.
